# 数据结构与算法学习路线图（新手 → 独立实操）

> 每个层级约需 2-4 周，视投入时间而定。**核心原则：每层必须动手写代码，光看不练等于没学。**

---

## 层级总览

```
L1 编程基础 + 复杂度分析
 │  进阶标准：能分析任意简单代码的时间/空间复杂度，Big O 无误
 │
L2 线性结构（数组 / 链表 / 栈 / 队列）
 │  进阶标准：从零实现四种结构，能手写所有基本操作
 │
L3 递归 + 基础排序
 │  进阶标准：手写 6 种排序，能画递归树，分析分治算法复杂度
 │
L4 树结构
 │  进阶标准：手写 BST + 堆 + 四种遍历，解决中等难度 LeetCode 树题
 │
L5 哈希表 + 图
 │  进阶标准：手写哈希表（含冲突解决），BFS/DFS 模板题 5 分钟内 AC
 │
L6 高级专题（DP / 贪心 / 高级树）
 │  进阶标准：独立 AC 30+ 道 DP 题，能区分贪心 vs DP 的适用场景
 │
L7 独立实操
   进阶标准：打 LeetCode 周赛稳定 2-3 题，参与开源项目或自建小项目
```

---

## L1: 编程基础 + 复杂度分析

### 学习内容

| 主题 | 核心知识点 |
|------|-----------|
| 语言基础 | 选定一门语言（推荐 Python / Java / C++），掌握：数组、循环、条件、函数定义 |
| 时间复杂度 | Big O / Ω / Θ 的定义；O(1)、O(log n)、O(n)、O(n log n)、O(n²)、O(2ⁿ) |
| 空间复杂度 | 原地算法（in-place）、递归栈空间、辅助空间 |
| 基本分析 | 单循环、嵌套循环、二分查找类型的分析；最好/最坏/平均情况 |

### 必做练习（5-8 题）

- 写 3 段不同复杂度的代码片段，分别分析复杂度
- 用定量的方式比较 O(n) 和 O(n²)：输入 10/100/1000/10000 的运行时间
- 分析一段含递归的代码（如斐波那契）的递归树大小

### 常见错误

1. **把循环层数当复杂度**：`for(i=0; i<n; i+=2)` 嵌套两层仍可能是 O(n)，要看实际执行次数
2. **忽略递归栈的开销**：分析递归算法时只看单次调用开销，忘记栈深度
3. **Big O 漏项**：O(2n) 应简写为 O(n)，但推导过程中不要直接跳步骤
4. **主导项判断错误**：认为 O(n + log n) ≠ O(n)

### 进阶标准 ✅

> 随便给一段 30 行内的代码（含循环、递归），能在 2 分钟内准确给出 Big O，并解释理由。

## L2: 线性结构（数组 / 链表 / 栈 / 队列）

### 学习内容

| 数据结构 | 核心操作 | 复杂度 |
|---------|---------|--------|
| 数组 | 随机访问、插入、删除、扩容 | 访问 O(1)，插入/删除 O(n) |
| 链表 | 单向/双向/循环；头插、尾插、删除、反转 | 查 O(n)，插/删 O(1) |
| 栈 | push / pop / peek；括号匹配、表达式求值 | 均摊 O(1) |
| 队列 | enqueue / dequeue；循环队列、双端队列 | O(1) |

### 必做练习（12-15 题）

- **从零实现**：动态数组（自动扩容）、单向链表（含 reverse）、栈、循环队列
- LeetCode：`206 反转链表` / `20 有效的括号` / `232 用栈实现队列` / `622 设计循环队列`
- 用链表实现 LRU 缓存的基本结构（不要求 O(1)，先用链表理解驱逐逻辑）

### 常见错误

1. **链表边界遗漏**：头节点、尾节点、空链表三种情况没覆盖
2. **指针/引用丢失**：反转链表时先断了后链就找不回来了——先保存 next 再操作
3. **栈和队列混淆**：栈是 LIFO，队列是 FIFO，用数组实现时注意方向
4. **循环队列判空/判满搞混**：`front == rear` 既可表示空也可表示满，没有区分标志

### 进阶标准 ✅

> 30 分钟内从零写完以上四种结构的完整实现（含注释），不用查资料，且边界 case（空、单元素、满）全部正确。

## L3: 递归 + 基础排序

### 学习内容

| 主题 | 核心知识点 |
|------|-----------|
| 递归三要素 | 终止条件（base case）、递推关系（recurrence）、参数变化方向 |
| 递归树分析 | 画递归树推导时间复杂度（如归并排序的 O(n log n)） |
| 基础排序 | 冒泡、选择、插入（O(n²) 级别，理解原理即可） |
| 分治排序 | 归并排序、快速排序（重点！理解分治思想和 partition） |
| 非比较排序 | 计数排序、桶排序（了解即可） |
| 稳定性 | 什么是稳定排序，哪些排序是稳定的 |

### 必做练习（10-15 题）

- 手写 6 种排序：Bubble / Selection / Insertion / Merge / Quick / Counting
- LeetCode：`509 斐波那契数`（理解递归 vs 迭代 vs 记忆化） / `50 Pow(x,n)`（快速幂，分治） / `215 数组中的第K个最大元素`（快排 partition 的应用）
- 用两种方法（递归 + 迭代）写二分查找

### 常见错误

1. **递归没有终止条件**：或终止条件永远达不到 → stack overflow
2. **快排 pivot 选得差**：始终选第一个/最后一个元素 → 有序数组退化为 O(n²)
3. **归并排序 merge 步骤丢元素**：两指针移动逻辑写错
4. **尾递归的误解**：以为写了就自动优化，但很多语言（如 Python）不自动做尾递归优化
5. **手写快排忘了 shuffle 或随机 pivot**：面试/考试中这是扣分项

### 进阶标准 ✅

> 手写 Merge Sort 和 Quick Sort（随机 pivot），不出 bug；能画递归树并推导 O(n log n)；能一眼判断某个排序算法是否稳定。

## L4: 树结构

### 学习内容

| 主题 | 核心知识点 |
|------|-----------|
| 二叉树基础 | 节点定义、满/完全/完美二叉树的区别、二叉树的性质（高度与节点数） |
| 遍历 | **前序 / 中序 / 后序**（递归 + 迭代）、**层序**（BFS 用队列） |
| 二叉搜索树 | 查找、插入、删除（三种情况：叶子/单子/双子）、验证 BST |
| 堆 & 优先队列 | 最小堆/最大堆、上浮 swim、下沉 sink、堆排序、Top-K 问题 |
| 其他树（了解） | 字典树 Trie、并查集 Union-Find（路径压缩、按秩合并） |

### 必做练习（15-20 题）

- 从零实现：BST（insert / delete / search / validate）、二叉堆（insert / extractMin）
- LeetCode：`94/144/145 三种遍历` / `102 层序遍历` / `98 验证BST` / `450 删除BST节点` / `215 第K大`（堆解法） / `347 前K个高频元素` / `208 实现Trie` / `547 省份数量`（并查集）

### 常见错误

1. **三种遍历混淆**：记不住「前=根左右，中=左根右，后=左右根」，写迭代版时栈顺序搞反
2. **BST 删除双子节点**：找后继（右子树最小节点）替代后忘了删除原来的后继
3. **堆的索引关系**：0-index 时 parent = (i-1)/2，leftChild = 2i+1，和 1-index 不同
4. **递归遍历时的空指针**：忘了判 `if root is None`
5. **把二叉树当 BST**：普通二叉树没有大小关系，不要做左侧全部小于根这种假设

### 进阶标准 ✅

> BST 的增删查 10 分钟内写完；前中后序的迭代版本能徒手写出；用堆解决 Top-K 类问题 5 分钟 AC。

## L5: 哈希表 + 图

### 学习内容

| 主题 | 核心知识点 |
|------|-----------|
| 哈希表原理 | 哈希函数设计、冲突解决（拉链法 / 开放寻址）、装载因子、rehash |
| 哈希应用 | 去重、计数、两数之和、缓存（LRU） |
| 图表示 | 邻接矩阵、邻接表、边列表 |
| 图遍历 | BFS（队列）/ DFS（递归+栈）、连通分量、拓扑排序（Kahn / DFS） |
| 最短路径 | Dijkstra（贪心）、Floyd-Warshall（DP）、Bellman-Ford（负权边） |

### 必做练习（15-20 题）

- 从零实现哈希表（拉链法 + 开放寻址两种，含 rehash）
- 从零实现图的 BFS 和 DFS（邻接表版本）
- LeetCode：`1 两数之和` / `146 LRU缓存` / `200 岛屿数量` / `207 课程表`（拓扑排序） / `743 网络延迟时间`（Dijkstra） / `133 克隆图` / `417 太平洋大西洋水流问题`

### 常见错误

1. **哈希冲突没处理**：只用取模，不考虑 key 冲突 → 数据丢失
2. **BFS 忘了 visited 标记**：导致重复入队，死循环或指数级性能下降
3. **DFS 爆栈**：递归深度的图太大 → Python 默认递归深度只有 1000
4. **Dijkstra 用了负数/普通队列**：Dijkstra 不支持负权边（要用 Bellman-Ford），且必须用优先队列
5. **图的边界遍历**：岛屿问题中坐标偏移没判断越界（row < 0, row >= m, col < 0, col >= n）

### 进阶标准 ✅

> 哈希表从零实现（拉链法），含 rehash；BFS/DFS 模板代码已形成肌肉记忆；5 分钟内 AC 一道中等难度的图遍历题。

## L6: 高级专题（DP / 贪心 / 高级树）

### 学习内容

| 主题 | 核心知识点 |
|------|-----------|
| 动态规划 | 最优子结构、重叠子问题、状态定义、状态转移方程；自顶向下（记忆化）vs 自底向上（递推） |
| 经典 DP | 背包（0-1/完全）、最长公共子序列 LCS、最长递增子序列 LIS、编辑距离 |
| 贪心 | 贪心选择性质、最优子结构；区间调度、Huffman 编码、跳跃游戏 |
| DP vs 贪心 | 什么时候贪心不 work？为什么需要 DP？ |
| 平衡树（了解） | AVL（旋转）、红黑树（概念）——理解为什么需要平衡 |

### 必做练习（25-30 题）

- **DP 入门（10 题）**：`70 爬楼梯` / `198 打家劫舍` / `62 不同路径` / `64 最小路径和` / `322 零钱兑换`
- **DP 进阶（10 题）**：`300 LIS` / `1143 LCS` / `416 分割等和子集`（0-1 背包） / `72 编辑距离` / `139 单词拆分`
- **贪心（5-8 题）**：`55 跳跃游戏` / `435 无重叠区间` / `452 用最少数量的箭引爆气球` / `122 买卖股票II`
- 做 3-5 道「贪心错误、DP 正确」的题目，体会两者的边界

### 常见错误

1. **DP 状态定义过早优化**：一开始就想压维度，应该先写出完整的二维/多维状态再优化
2. **DP 顺序写反**：递推方向与状态转移方向不一致，用了还没算出来的值
3. **背包问题内层循环顺序**：0-1 背包是倒序、完全背包是正序，搞反了
4. **贪心不验证**：凭直觉认为贪心可行就写，没举反例验证 → WA（Wrong Answer）
5. **混淆 DP 和回溯**：DP 求最优值，回溯求所有方案，两者适用场景不同

### 进阶标准 ✅

> 能独立 AC 30 道 DP 题；拿到一道新题能判断「该用贪心还是 DP」，并说出理由；能写出 0-1 背包的滚动数组优化版本。

## L7: 独立实操

### 做什么

| 路径 | 具体做法 |
|------|---------|
| **刷题平台** | LeetCode 每日一题 + 周赛；按标签刷薄弱点（DP / 图 / 树 / 贪心） |
| **经典书籍** | 《算法导论》选读 / 《剑指 Offer》 / 《labuladong 的算法小抄》 |
| **开源贡献** | 给自己用的开源库修 bug → 看源码中的数据结构应用（如 Redis 跳表、Linux 内核链表） |
| **造轮子项目** | 实现一个简单的数据库索引（B+ 树）、一个小型解释器（AST 遍历）、一个路径规划工具 |
| **可视化** | 用 Python + matplotlib 或 D3.js 可视化排序过程 / 路径搜索过程 |

### 常见错误

1. **刷题不看题解**：WA 后反复蛮干，不学习最优解——会做 ≠ 做得漂亮
2. **只刷 Easy**：在舒适区待太久，不敢碰 Medium/Hard
3. **只刷不总结**：同样的 trick 换个皮就不会了——每 10 题做一次归类总结
4. **面试前突击**：算法需要长期积累，突击只能应付简单题
5. **脱离场景学算法**：不知道红黑树实际用在哪（epoll、Timer、std::map）→ 遗忘快

### 进阶标准 ✅

> LeetCode 周赛稳定 2-3 题；能独立设计一个小系统的核心数据模块（如排行榜用堆+哈希表，路由规划用图）；给他人 review 算法代码能指出优劣。

## 学习技巧总纲

1. **费曼学习法**：每学完一个结构，假装教给别人，用白板/纸讲一遍——讲不清楚的地方就是没懂的
2. **先理解再记忆**：不要背代码模板，要在纸上画过程（链表指针变化、递归树展开、DP 表格填值）
3. **规律复习**：学完 L3 后回头做 L2 的题；学完 L5 后回头做 L3 的排序题——隔周复习效果最好
4. **一题多解**：每道中等题至少用两种方法解决（如用 BFS + DFS 各做一遍图的遍历）
5. **做好笔记**：每个常见错误就是未来面试的踩坑点，记录下来形成自己的「排错手册」
